MyOS is a small personal desktop-style website inspired by an operating system.

## Features

- Draggable desktop applications
- Music application with favorite artists
- Images gallery
- Hobby application
- Draggable windows
- Apps stay inside the screen
- Windows can push desktop apps

## Technologies

- HTML
- CSS
- JavaScript
